# 0. 总框架图（建议单独半页或两页顶上的通栏）

原文没有一张端到端总图，汇报时建议自己补一张。画成 **从左到右三列厂房**：

```
┌─────────────┐    ┌──────────────────┐    ┌─────────────────┐
│ ① 表示工厂   │ →  │ ② 写句子工厂      │ →  │ ③ 装配工厂       │
│ 几何+拓扑    │    │ GPT 自回归抽样    │    │ 点阵→曲面→缝合   │
│ → 离散 token │    │ → 长 token 序列   │    │ → STEP 实体      │
└─────────────┘    └──────────────────┘    └─────────────────┘
```

更细一点的通栏流程（可做成横向图标链）：

```
CAD 实体
  → 每个面采 32×32 点、每条边采 32 点
  → 形状压成几个整数码 + 位置压成包围盒整数
  → 拓扑变成「指回旧面」的写法
  → 拼成一条句子
  → Transformer 像写文章一样往下写
  → 整数码还原成点阵，点阵拟合成面/边，缝成实体
```

页内小标题可写：`我们补一张「原文没有的」端到端框架，用来串起后面两页。`

## 左栏｜几何怎么编码（请画成「面」一条竖流水线 + 「边」一条缩略旁路）

### 栏标题（大）
`几何：点阵 → 潜空间格子 → 整数码`

### 主路径：一个面（务必标出张量形状）

**第 1 步｜在曲面上采点**  
图：一块弯曲曲面，上面铺满规则点阵。  
文字：
- 在参数域均匀采样，得到 **一张点网格**  
- 形状：**`(32, 32, 3)`**  
  - `32×32`：参数域上的格子  
  - `3`：每个格子一个 xyz 坐标  
- 先放进局部归一化盒子 `[-1,1]³`（去掉平移缩放，只留「形状」）  
- 额外做 UV 起点规范化：四个角里字典序最小的角固定为原点（避免同一曲面因参数起点不同变成「另一种样子」）

**第 2 步｜深度压缩成小潜空间**  
图：大网格被漏斗吸进一个很小的 2×2 色块。  
文字（按原文设定讲清楚手段）：
- 用 **深度压缩自编码器（Deep Compression Autoencoder）** 把点阵压小  
- （对比旧方法：曾压到约 `4×4×3`；这里进一步压到更小，好让后面 GPT 少写几个词）  
- 得到连续潜变量网格：**`(2, 2, 4)`**  
  - 空间上 `2×2` 四个位置  
  - 每个位置一个 **4 维**连续向量  

**第 3 步｜FSQ：把连续数「咬」成整数码**  
图：四个小向量，每一维被尺子刻成有限档，再合成一个整数编号。  
文字：
- 使用 **有限标量量化 FSQ**（不是普通 VQ 查大表那种）  
- 对潜向量每个维度按规定档位取整；档位配置 **`[8,5,5,5]`** → 码本大小 **`8×5×5×5=1000`**  
- 每个空间位置变成 **1 个整数码**  
- `2×2` 个位置 → **每个面最终 4 个几何整数 token**

**第 4 步｜还要单独记下「放在哪」**  
图：形状归一化后丢了全局位置，所以再套一个世界坐标系下的线框盒子。  
文字：
- 包围盒两个角：`min` 与 `max`，共 **6 个数**  
- 每个坐标轴把 `[-1,1]` 切成 **1024** 档 → **6 个位置整数 token**  
- 口诀：`位置 token 在前，形状码在后` → 模型先知道大小方位，再填细节

### 旁路小条：一条边（右下角缩略，别抢戏）
```
边：参数域采 32 个点 → 张量 (32, 3)
  → 1D 压缩到约 (2, 4) 连续潜变量
  → FSQ → 每个边 2 个整数码
  → 同样再配 6 个包围盒位置 token
```

### 左栏一句话收束
`训练时：点阵进编码器得到整数码；推理生成时：模型直接吐整数码，再反向走解码器变回点阵。`

（左栏用虚线小箭头标出「反向」：`整数码 → FSQ 逆变换回连续 (2,2,4) 嵌入 → 上采样/解码器 → 还原 (32,32,3)` —— 这句很重要，导师常问。）

## 右栏｜拓扑怎么编码

### 栏标题（大）
`拓扑：不存一张大矩阵给网络，而写成「指回旧面」`

### 竖向四步

**T1｜先有「谁和谁共边」的事实**  
图：简化零件拆成几张面；高亮两条面夹着一条共享边。  
文字：每条流形边恰好属于两个面。

**T2｜建成「面=房间、共享边=门」的邻接图**  
图：圆点是面，连线表示有门相通。

**T3｜按广度优先决定书写顺序**  
图：从「包围盒排序最靠前」的面当起点，一圈圈向外扩展。  
文字：句子顺序 = 在邻接图上逛房间的顺序（BFS），不是乱序罗列。

**T4｜用 Face ID 当名字：声明一次，以后用名字把门写出来**  
左小卡「声明」：
```
开始一个面 → 给它名字 FaceID=k → 写下它的位置盒 + 4 个形状码
```
右小卡「引用（这就是拓扑）」：
```
写到新面时，若与旧面共边：
  写上「旧面的 FaceID」→ 再写这条边的位置盒 + 2 个边形状码
```
金句（大字）：  
`Face ID 像通讯录里的名字：embedding 学的是「可指代」，不是「长得像圆柱」。`

## 上半｜序列化生成（像写长文）

### 标题条
`A. 自回归写句子`

**起点（画成聊天输入框）**  
无条件时人只提供很弱的前缀，例如：  
`开始 | 元信息开始 | 复杂度=中 | 元信息结束 | 开始写CAD`  
强调：`这里没有「请生成带孔立方体」这种语义。`

**引擎（中间大块）**  
画一个「下一词预测」循环：

1. 看已经写好的前缀  
2. 对词表打分  
3. **先截断低概率尾巴（nucleus / top-p）**  
4. **用温度软化分布**  
5. **按概率随机抽一个下一个整数 token**（不是每次都取最高分）  
6. 接到句子末尾，重复  

小提示条：  
`同前缀能长出不同零件，是因为第 6、7、8… 个词在抽样，不是前缀本身在抖。`

**写出的长句长什么样（示意滚动纸带）**
```
层0：只写第1个面（有名字+位置+形状，还没有边）
层1：写邻居面；每来一个新面，就「点名旧面」并写出共享边
层2：继续向外…
结束 CAD
```

---

## 中带｜把句子拆成三张表（装配前的中间态）

标题：`B. 读懂句子`

三张卡片并排：

1. **面表**：每个面 → 6 个位置整数 + 4 个形状整数  
2. **边表**：每条边 → 6 个位置整数 + 2 个形状整数  
3. **邻接**：每次「点名旧面」→ 记一条「新面—旧面 共享该边」

然后画 **几何逆变换放大镜**（对应你说的 FSQ 逆向）：

```
形状整数码
  → FSQ 逆映射：整数 → 连续潜向量，拼回 (2,2,4)（面）或对应边的潜格子
  → 解码器上采样并重建
  → 还原点阵：面约 (32,32,3)，边约 (32,3)
  → 再用包围盒把局部点阵搬回世界坐标
```

口播金句：  
`生成时吐的是码；装配前必须先把码「解冻」回点坐标。`

---

## 下半｜组装成 STEP（焊工流水线）

### 标题条
`C. 从点阵焊成实体文件`

五步横滑（图标要具体）：

1. **对齐该重合的角点**  
   多条边端点挤在一起 → 合并成共享顶点（距离阈值）

2. **联合微调**  
   轻轻拉扯面网格与边折线，让它们贴紧共享顶点，减少缝隙

3. **点列拟合参数曲面/曲线**  
   面点阵 → B 样条曲面；边点列 → B 样条曲线  
   （拟合失败会放宽容差再试）

4. **用边围成线框去裁剪面，再把面缝起来**  
   - 外环、内环（通孔时：外框 + 内圆孔）裁出一张面  
   - 多张面 Sewing；能封闭则做成 Solid  

5. **写出 STEP 文件**  
   得到可在 CAD 软件打开的实体

### 橙色警告角
标题：`哪里会失败？`  
- 句子可能已经写完（甚至能画出点阵预览）  
- 但第 C 步缝合失败 → **没有 STEP**  
- 所以：`会写字 ≠ 焊得住`

# 给做图 AI 的硬约束清单

# 演讲者 2 分钟口播稿（可放备注）

**第 1 页**  
「先看左：每个面是 32×32 的 xyz 网格，压成 2×2×4 的连续格子，再 FSQ 咬成 4 个整数；边同理变成 2 个整数；位置另用包围盒 6 个数。  
再看右：拓扑不靠再输一张大表，而是给面起名，写新面时点名旧面并吐出共享边。  
底下这条胶带就是一个面在句子里的完整短语。」

**第 2 页**  
「生成就是从很短的前缀开始，按概率一个个往下抽整数。  
抽完后先把形状码解冻回点阵，再拟合曲面、裁剪、缝合，才有 STEP。  
很多失败发生在最后焊接，不代表前面没写出几何。」
